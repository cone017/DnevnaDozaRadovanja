Android application about professor of history Radovan Damjanovic.

Application was made as a school project.

Main parts are recyclerview and something similar to music player.

Recyclerview use data from online json file and convert it to non-clickable-cards.

On the page for playing sounds, when button is clicked, it change image in it, according whether if it's playing, or it's paused.
